# Release notes

## Breaking changes

- `Misc.Version` does not use the value -1 anymore to mark the build and the revision as not set: `Major` and `Minor` are now of the type `uint` and `Build` and `Revision` are now of the type `uint?` (`null` means "not set"; additionally there are the new properties `HasBuild` and `HasRevision`). Negative values are therefore impossible by construction and the constructors which accept `int`-values reject negative values explicitly.

## Changes

- Fix `AOA.EqualsHelper.CustomComparer.EnumerableComparer` comparing the comparer-instance with the searched item instead of comparing the items of the enumerables, which made every two enumerables with the same length equal
- Fix `Crypto.SHA256PureCSharp` appending an additional block of zero-bits while padding, which resulted in a non-standard hash for every message whose length is 55+64*n bytes
- Fix `Misc.Semaphore.Lock` waiting inside the lock-block which `Misc.Semaphore.Unlock` needs, which resulted in a deadlock
- Fix `Misc.IdGenerator.GeneratedIds` always returning an empty set
- Fix `Misc.Utilities.IncrementGuid` returning wrong values or throwing for guids whose highest hex-digit is greater than or equal to 8
- Fix `Misc.Utilities.ToCaseInsensitiveSet` not removing items which only differ in their casing
- Fix `Misc.Utilities.ContainsSublist` matching parts of items instead of complete items, which also affected `Misc.ByteArray.Contains`
- Fix `Misc.Utilities.GetRandomAlphaHexCharacter` being able to return two characters instead of one single hex-letter
- Fix `Misc.Utilities.Cast` not being able to convert types like `KeyValuePair` and `Tuple` and not being able to convert between convertible value-types
- Fix `CompareTo(object)` of `Misc.GRYDateTime`, `Misc.GRYDate` and `Misc.GRYTime` always throwing an `ArgumentException`
- Fix the equals-operator of `Misc.ByteArray` throwing for `null` and `Streams.StreamMixer.StreamPipe.Equals` throwing for objects of another type
- Fix `Misc.FileCache` writing its cache-file without the configured encoding
- Fix `Misc.Version3.Parse` not accepting values which are greater than 65535
- Fix `Misc.Version.ToSystemVersion` throwing for versions whose build or revision is not set and `Misc.Version` not accepting a `System.Version` without build and revision
- Fix `Graph.DirectedGraph.CreateByAdjacencyMatrix` creating edges for entries with the weight 0 and not registering the created edges at their vertices
- Fix `Graph.Graph.ContainsOneOrMoreCycles` reporting every undirected graph with at least one edge as cyclic
- Implement `Graph.Graph.GetAllCyclesThroughASpecificVertex`, so `Graph.Graph.GetAllCycles` and `Graph.Graph.HasHamiltonianCycle` work now
- Correct the documentation of `Misc.GRYDate`, `Misc.GRYTime`, `Misc.IdGenerator` and `Misc.Utilities.ParseDateAmericanFormat`
- Document known issues and open topics in the hints of the code-unit

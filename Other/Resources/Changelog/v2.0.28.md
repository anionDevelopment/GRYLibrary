# Release notes

## Changes

- Fix `APIServer.Services.Res.GeneralResourceLoader` caching its resources in a plain `Dictionary`. The loader is a singleton whose cache is filled while requests are processed, so concurrent accesses corrupted the dictionary permanently and made the application answer no request anymore until it was restarted. The cache is a `ConcurrentDictionary` now and is filled via `GetOrAdd`.
- `APIServer.MidT.Exception.ExceptionManagerMiddleware` calls `GetNotFoundResponseContent` now. That extension-point existed and was implemented by applications, but it was never invoked: the middleware only acted when an exception was thrown, while a request whose address belongs to no route does not throw but simply results in the status-code 404 with an empty body. Every address which does not exist therefore answered with an empty page (chromium showed a white page, firefox aborted with `NS_ERROR_NET_EMPTY_RESPONSE`). The middleware now offers the new overridable method `HandleNotFound`, which the default-implementation uses to fill such a response; it does nothing when the application does not provide content for it, so an application which does not want an own page keeps its previous behaviour.
- The request-rate-limiting (`APIServer.MidT.RateLimit.RateLimitingMiddleware`) only applies to a real run now (the commandline-parameter `RealRun`). Reason: an automated test drives an application without the pauses a human makes between two requests and reaches the limit within seconds, so it would be testing the rate-limiting instead of what it wants to check. The constructor of the middleware therefore takes an additional `IAPIServerCommandlineParameter`, which every derived middleware has to pass on.
- The generated captcha-picture has fixed dimensions now (260x80 by default, configurable via `CaptchaGenerationSettings`). Its width depended on the content before, so every page which shows a captcha had a slightly different layout depending on which captcha was generated for it.
- Updated the versions of the used images
- Removed the configuration of GitVersion, which is not used anymore

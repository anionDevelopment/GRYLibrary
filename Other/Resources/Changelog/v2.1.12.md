# Release notes

## Changes

- Added `HostMaintenanceRoutes.RoutePrefix` to host the maintenance-routes under a configurable path-prefix (for example `/MyApp/API/Other/Maintenance/HealthCheck`)
- If `TrustForwardedHeader` is enabled, the client-ip-address is now taken from the last entry of the `X-Forwarded-For`-header, which is the one appended by the trusted reverse-proxy (before, a header with several addresses caused an exception and the address could be spoofed by the client)

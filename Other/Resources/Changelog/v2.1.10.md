# Release notes

## Changes

- Fixed the security-finding `SEC-4`: an `AuthorizeAttribute` without groups no longer disables the authorization-check. `AuthorizationMiddleware.AuthorizationIsRequired` now requires authorization whenever an `AuthorizeAttribute` is present, so an empty authorized-groups-set fails closed (the request is denied) instead of admitting every authenticated user. Added regression-tests (`AuthorizationMiddlewareTests`).
- Added a direct reference to `MySqlConnector` `2.6.2` to override the transitive `MySqlConnector` `2.4.0` (pulled in by `Pomelo.EntityFrameworkCore.MySql` `9.0.0`), which has the advisory `GHSA-473q-m89c-ghf8` (moderate; a clear-text password could be sent before the certificate is validated when `SslMode` is `VerifyCA`/`VerifyFull` without a configured CA-certificate). The advisory is fixed in `MySqlConnector` `2.6.1`.

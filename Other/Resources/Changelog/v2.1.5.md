# Release notes

## Changes

- update
- Fixed: the commit (and rollback) of a transaction which is run by `DBUtilities.RunTransaction` timed out after 30 seconds although its statements had a timeout of 300 seconds. Npgsql and MySqlConnector complete a transaction with the default command-timeout of the connection and not with the timeout of the commands of the transaction. `PostgreSQLDatabaseInteractor` and `MariaDBDatabaseInteractor` now raise the default command-timeout of their connection-string to `DBUtilities.TransactionTimeoutInSeconds` (300 seconds; a higher value or 0 is kept). On systems with slow or shared disks a commit can take longer than 30 seconds, and a timeout during a commit leaves it undetermined whether the database applied the transaction.
- The test-project uses `NuGetAuditMode` `all` like the library itself, so it matches the standardized csproj-format again.

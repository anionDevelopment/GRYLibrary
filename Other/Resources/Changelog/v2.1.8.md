# Release notes

## Changes

- Fixed `FunctionsForCommonProjectStructure.GetConstantProperties` to register the `cps` XML-prefix with the common-project-structure namespace at version `v3.0.4` instead of the previously hardcoded `main`-branch URL. Repositories whose `*.constant.xml` files declare `.../tree/v3.0.4/...` (as emitted by ScriptCollection with `CommonProjectStructureVersion = "3.0.4"`) could not be processed before: the XPath lookup `/cps:constant/cps:name` returned `null` and `GenerateConstants` crashed with a `NullReferenceException` during T4-transform, aborting `scbuildcodeunits` for any codeunit with `.tt`-templates that call this helper.

# Release notes

## Changes

- fix
- Utilities.IsAdministrator is implemented for OSX and Linux now. On unix-based operating-systems there is no equivalent
  of the windows-administrator-role, so the effective user-id is used: the function returns true if and only if the
  process runs as the user "root". Before that, the function threw a NotImplementedException on both operating-systems.
- Utilities.TryResolvePathByPathVariable is implemented for OSX now. It uses the same implementation as Linux, because
  all unix-based operating-systems separate the entries of the path-variable by ":" and resolve a program to an
  executable file.
- Utilities.DarkModeEnabled is implemented for OSX and Linux now. On OSX the state is read using
  "defaults read -g AppleInterfaceStyle" and set using osascript, on Linux the setting
  "org.gnome.desktop.interface color-scheme" is read and set using gsettings. On a Linux-system which does not provide
  that setting, reading the state throws a NotSupportedException which names the missing setting instead of returning a
  wrong value.
- Fixed the operating-system-check of Utilities.IsAdministrator: the handlers for OSX and Linux checked whether the
  current operating-system is windows, so they could never have reached an implementation for their own
  operating-system.

# Release notes

## Changes

- Each finding of the "OWASP-Top-10-analysis"-section in the readme now carries a "Fixable without breaking changes"-line. It
  states for every one of the 37 findings whether it can be remediated in a way which is definitely not a breaking change for a
  consumer (no behaviour-change when the library is used as intended, no additional configuration required and no
  interface-change), as "Yes", "No" or "Partial", with a short reason. The findings which are breaking-change-free are GRY-09
  (drop the unused `System.Data.SqlClient`-reference), GRY-10 (`NuGetAudit`-settings affect only the own build), GRY-12
  (implement the throwing `Argon2.Hash` and add a `PasswordHasher`), GRY-15 (parameterize the migration-statements), GRY-17 (add a
  concrete opt-in rate-limiting-middleware), GRY-22 (mark the resource-owner-password-grant obsolete), GRY-25 (remove the
  discarded token-lookup), GRY-27 (send and validate the oidc-nonce), GRY-28 (offer a hash-chaining log-target), GRY-29 (complete
  the strong-name-signature) and GRY-33 (log the swallowed authentication-exception). The remainder are "No" or "Partial".

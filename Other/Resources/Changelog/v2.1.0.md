# Release notes

## Changes

- Added OIDC.
- Added OIDC password-flow (`IOIDCService.LoginWithPasswordAsync`) so an application can delegate a classic username/password-login to an OIDC-provider (e.g. Keycloak) and return the resulting access-token to the client.
- Added OIDC access-token-validation (`IOIDCService.ValidateAccessTokenAsync`); `AuthSMiddleware` now also accepts OIDC-tokens on incoming requests when an `IOIDCService` and an `IOIDCAuthenticationConfiguration` are registered.
- Added support for confidential OIDC-clients (client-secret) and configurable scope and audience per provider, plus an `AddOIDC`-extension to register the OIDC-service in the dependency-injection-container.
- Added a reference-article that explains how to use the OIDC-functionality in a project.

# Release notes

## Changes

- the links of the common routes can be null; a route whose link is null is not hosted and is not named in the
  api-specification anymore
- the environment-variable which states that an application runs in a container is compared without case now, so an
  image which writes its name in another case is recognized as well instead of silently moving every folder of the
  application
- new function "Utilities.GenerateSecureRandomValue", which creates a hexadecimal value of a stateable length from the
  random-generator of the operating-system

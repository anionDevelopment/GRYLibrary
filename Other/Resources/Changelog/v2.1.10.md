# Release notes

## Changes

- `Tools.WaitUntilDatabaseIsAvailable` no longer counts an attempt as failed while the database is reachable but still starting up (PostgreSQL SQLSTATE 57P03 "cannot_connect_now", for example during the crash-recovery after an unclean shutdown). Before, the fixed amount of attempts (about 2 minutes 20 seconds with the default values) could run out while a database on a slow disk was still running its end-of-recovery-checkpoint, so the initialization of the application failed although the database became available shortly afterwards. All other reasons for an unavailable database still consume the attempts as before. The detection is available as `DBUtilities.IsCausedByDatabaseStartingUp`.
- Added a direct, pinned reference to MySqlConnector 2.6.2 (before: 2.4.0, only referenced transitively via Pomelo.EntityFrameworkCore.MySql 9.0.0, which is the latest version of Pomelo). MySqlConnector before 2.6.1 is affected by GHSA-473q-m89c-ghf8 (MitM password disclosure in zero-configuration TLS mode), and the NuGet-audit treats this as an error, so the codeunit could not be restored anymore. GRYLibrary uses MySqlConnector directly in `MariaDBDatabaseInteractor`, so the direct reference also makes this dependency explicit.
- Security-fix (finding SEC-4): An `AuthorizeAttribute` without groups does not disable the authorization-check anymore. Before, `AuthorizationMiddleware.AuthorizationIsRequired` returned `false` for an empty authorized-groups-set, so such an annotated action admitted every authenticated user. Now the presence of an `AuthorizeAttribute` always requires the authorization-check, and the check is performed with no group being accepted (fail-closed). Consumers which used `[Authorize]` without groups to admit every authenticated user have to use `[Authenticate]` instead.
- Updated Swashbuckle.AspNetCore from 10.3.0 to 10.3.1.
- Updated the build-image SCBuilder from v1.2.18 to v1.2.19 and added a Squid-image-definition and an agent-sandbox-configuration for the usage of coding-agents in containers.

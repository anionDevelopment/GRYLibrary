# Release notes

## Changes

- added fb structure generation function
- fix
- Fixed Utilities.NormalizePath: the leading double-separator of an UNC-path (for example "\\server\share") was reduced to a single separator by the duplicate-reduction and is preserved now.
- Utilities.NormalizePath now throws an ArgumentException for a path which starts with more than two separators ("///" respectively "\\\"), because such a path is not valid.

# Release notes

## Changes

- Added `Misc.ExclusiveAccess`. It grants exclusive access to a resource for the entire duration of an operation: whoever needs the resource waits until the current user is finished with it. In contrast to a plain `SemaphoreSlim` it is re-entrant for the owning thread, so an operation on the protected resource can call another operation on the same resource without deadlocking itself. In contrast to a `lock`-statement the protected resource can be replaced while it is protected, because the access is bound to the `ExclusiveAccess`-object and not to the resource-instance.

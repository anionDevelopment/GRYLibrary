# Release notes

## Changes

- Raised the `codeunitspecificationversion` of the `GRYLibrary`-codeunit (and the corresponding `codeunit.xsd` schema-location) from `3.0.0` to `3.0.4`, so that the codeunit-file is validated against and conforms to the common-project-structure-specification version `3.0.4` which the rest of the repository already references.
- Updated Swashbuckle.AspNetCore from 10.2.3 to 10.3.0, which is the version of the `swagger`-CLI-tool (`swashbuckle.aspnetcore.cli`) installed in the SCBuilder-build-image; the previous mismatch made the `swagger tofile`-step of the api-specification-generation of the products which consume this library fail, because the CLI-tool could not load its matching `Swashbuckle.AspNetCore.Swagger`-assembly from the build-output.

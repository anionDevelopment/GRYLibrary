# Release notes

## Changes

- updated timeout for migrations
- Added IteratingBackgroundService.RunAlsoWhenTheExecutionModeIsNotRunProgram. A background-service was only started when the
  execution-mode is RunProgram, which made it impossible for an application to run its background-services in a test-run, even
  when the testcase exists to check what these services really do. The execution-mode does not carry that information, so the
  application decides it now. The default of the new property keeps the previous behaviour.

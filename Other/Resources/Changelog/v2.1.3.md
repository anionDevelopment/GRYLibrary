# Release notes

## Changes

- `ExternalProgramExecutor.Terminate` now really ends the executed program and every program which was started by it.
  It called `Process.Close` before, which only releases the handle of the process, so a program which was executed
  asynchronously kept running although the caller asked for its end.
- `ExternalProgramExecutor.Dispose` now ends the executed program if it is still running. It did nothing before, so a
  program which was executed asynchronously outlived the `using`-block which executed it.
- The execution of a program which is executed asynchronously is now completed when the program ends. Before that
  `IsRunning` stayed true for ever, `ExitCode`, `ExecutionDuration`, `AllStdOutLines` and `AllStdErrLines` never became
  available, `ExecutionFinishedEvent` was never raised, a configured `TimeoutInMilliseconds` was ignored and the thread
  which logs the output of the program never ended.

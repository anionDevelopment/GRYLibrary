# Release notes

## Changes

- the links of the common routes can be null; a route whose link is null is not hosted and is not named in the
  api-specification anymore
- the environment-variable which states that an application runs in a container is compared without case now, so an
  image which writes its name in another case is recognized as well instead of silently moving every folder of the
  application
- serializing an object does not walk its whole object-graph a second time anymore to collect extra types which the
  serializer does not use yet; for a large object that walk was the largest part of the serialization
- "Generic.GenericGetHashCode" states the values of an object and not only its type, so a hash-set of such objects
  stops degenerating into a list in which every insert and every lookup compares against everything it contains
- "ReferenceTuple" has a hash-code of its own instead of one which is the same for every tuple, and its
  "Equals(object)" does not call itself endlessly anymore
- the comparison of two objects looks up the equivalence-class of an object directly instead of searching through every
  class which exists so far, and asks an equivalence-class whether it contains an object instead of copying its whole
  content for that question
- the comparison of two sets compares the elements which share a hash-code first
- new function "Utilities.GenerateSecureRandomValue", which creates a hexadecimal value of a stateable length from the
  random-generator of the operating-system
